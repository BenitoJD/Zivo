# Communication Preferences

- Direct, informal, stream-of-consciousness. Uses "See, ..." as a sentence opener to introduce new ideas. Confidence: 0.95
- Gives multiple requests in a single turn — often 4–8 distinct asks layered together. All must be tracked; missing any is a serious failure. Confidence: 0.98
- "I want you to scan the whole repo/re-read the chat and find what you missed" — repeated phrase when the user senses incomplete delivery. Expectation is 100% completion, not 70%. Confidence: 0.98
- "Don't stop till we perfect it" — perfectionist standard, iterates until satisfied. Confidence: 0.95
- Explicitly rejects the "it's benign" dismissal of issues. If the user reports it, it must be investigated and fixed, not explained away. Confidence: 0.95
- Prefers the agent to be autonomous and proactive — "I'm giving you complete freedom," "I'm sitting back," "wire everything." Does not want to micromanage. Confidence: 0.95
- Prefers high-level explanations in non-technical language when asking "how does X work?" — wants to understand the flow, not the implementation details. Confidence: 0.85
- Will ask "What's the root cause?" and wants the answer, not the symptom. Confidence: 0.9
- Repeats critical constraints 2-3× in a single message for emphasis (e.g., "seamless for the user" repeated multiple times). Repetition signals importance, not carelessness. Confidence: 0.85
- Sends screenshots of UI problems with vague descriptions — expects agent to visually inspect and understand the issue. Confidence: 0.8
- Phrases that signal high importance: "world-class," "think Steve Jobs," "don't miss," "very very important," "this is the foundation." Confidence: 0.9
- Will express frustration indirectly ("you missed a lot of things," "so you have forgot") rather than with anger. Expects the gap to be closed without defense. Confidence: 0.85
- Prefers the agent to summarize what was done and what remains in a structured way, not as a free-form narrative. Confidence: 0.75
- Product vision matters deeply — references `docs/VISION.md` and wants all decisions aligned to it. The app is "a question company," not a study tool. Confidence: 0.9
